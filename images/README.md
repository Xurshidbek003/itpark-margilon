# Rasmlar

Rasmni shu papkalarga quyidagi nomlar bilan qo'ying — sayt ularni avtomatik ko'rsatadi.
Rasm bo'lmasa, o'rnida pastel muqova (kurslar) yoki ism bosh harflari (ustozlar) chiqadi.

## kurslar/  (tavsiya: 1200x900 px, .jpg, 300 KB dan kichik)
it.jpg, ingliz.jpg, matematika.jpg, koreys.jpg, nemis.jpg, sertifikat.jpg

## ustozlar/  (tavsiya: 800x920 px, vertikal portret, .jpg)
azizbek.jpg, madina.jpg, jasur.jpg, jiwoo.jpg, nodira.jpg, sardor.jpg

Boshqa nom ishlatmoqchi bo'lsangiz, data.js dagi `image` / `photo` maydonini o'zgartiring.
